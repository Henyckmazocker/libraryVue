Acerca de los Composables

Los composables de Vue 3 proporcionan lógica reutilizable y reactiva para diferentes aspectos de la aplicación, siguiendo el patrón de Composition API.

Composables de Autenticación

useAuth

Composable principal que proporciona funcionalidades básicas de autenticación.

Estados Reactivos
const {
  // Estados del usuario
  user,              // Object: Datos del usuario autenticado
  isAuthenticated,   // Boolean: Si el usuario está autenticado
  isLoggedIn,        // Boolean: Si el usuario está logueado
  userName,          // String: Nombre del usuario
  userEmail,         // String: Email del usuario
  userPicture,       // String: URL de la imagen del usuario
  
  // Estados de la aplicación
  isLoading,         // Boolean: Si hay operaciones en curso
  error,             // String: Mensaje de error actual
  csrfToken,         // String: Token CSRF para operaciones protegidas
  jwtToken,          // String: Token JWT
  lastLoginAttempt,  // Date: Fecha del último intento de login
} = useAuth();
Métodos Principales
initializeAuth()

Inicializa el sistema de autenticación y verifica el estado del usuario.

logout()

Cierra la sesión del usuario y limpia los tokens.

refreshToken()

Actualiza el token de autenticación cuando es necesario.

checkAuth()

Verifica el estado de autenticación actual.

Ejemplo de Uso
// En un componente Vue
import { useAuth } from '@/composables/useAuth'

export default {
  setup() {
    const { user, isAuthenticated, logout } = useAuth()
    
    const handleLogout = async () => {
      await logout()
      router.push('/login')
    }
    
    return {
      user,
      isAuthenticated,
      handleLogout
    }
  }
}

useGoogleAuth

Composable especializado para la integración con Google OAuth.

Estados Reactivos
const {
  googleUser,        // Object: Datos del usuario de Google
  isGoogleLoading,   // Boolean: Si está procesando login de Google
  googleError,       // String: Error específico de Google
} = useGoogleAuth();
Métodos
initGoogleAuth()

Inicializa la biblioteca de Google OAuth.

signInWithGoogle()

Inicia el proceso de login con Google.

usePermissions

Composable para gestión de permisos y rutas protegidas.

Estados Reactivos
const {
  permissions,       // Array: Lista de permisos del usuario
  hasPermission,     // Function: Verifica si tiene un permiso específico
  canAccess,         // Function: Verifica acceso a rutas
} = usePermissions();

Composables de Biblioteca

useBooks

Composable para la gestión completa de libros en la biblioteca personal.

Estados Reactivos
const {
  books,             // Array: Lista de libros del usuario
  isLoading,         // Boolean: Si hay operaciones en curso
  error,             // String: Mensaje de error
  totalBooks,        // Number: Total de libros
  searchResults,     // Array: Resultados de búsqueda
} = useBooks();
Métodos Principales
fetchBooks()

Obtiene la lista de libros del usuario.

addBook(bookData)

Agrega un nuevo libro a la biblioteca.

updateBook(id, data)

Actualiza los datos de un libro existente.

deleteBook(id)

Elimina un libro de la biblioteca.

searchBooksByISBN(isbn)

Busca información de libros por ISBN.

updateBookRating(id, rating)

Actualiza la calificación personal de un libro.

useSearch

Composable avanzado para búsquedas con debounce y filtros múltiples.

Estados Reactivos
const {
  searchTerm,        // String: Término de búsqueda actual
  searchResults,     // Array: Resultados de la búsqueda
  isSearching,       // Boolean: Si hay una búsqueda en curso
  searchError,       // String: Error de búsqueda
} = useSearch(searchFunction, { debounceMs: 300 });
Características
Debounce

Evita búsquedas excesivas con delay configurable.

Filtros

Soporte para filtros múltiples y combinados.

Ejemplos de Uso

Ejemplo Completo: Gestión de Libros
// BookManager.vue
import { useBooks } from '@/composables/useBooks'
import { useAuth } from '@/composables/useAuth'

export default {
  setup() {
    const { books, addBook, isLoading, error } = useBooks()
    const { isAuthenticated } = useAuth()
    
    const handleAddBook = async (bookData) => {
      if (!isAuthenticated.value) return
      
      try {
        await addBook({
          ...bookData,
          user_rating: bookData.rating || null
        })
      } catch (err) {
        console.error('Error agregando libro:', err)
      }
    }
    
    return {
      books,
      handleAddBook,
      isLoading,
      error
    }
  }
}

Mejores Prácticas

✅ Hacer
  • Usar destructuring para importar solo lo necesario
  • Validar autenticación antes de operaciones
  • Manejar errores apropiadamente
  • Usar watchers para reactividad
❌ Evitar
  • Llamar métodos de API sin verificar autenticación
  • Ignorar estados de loading
  • No manejar errores de red
  • Mutar directamente los estados reactivos
Patrón Recomendado

Siempre combina composables relacionados (ej: useAuth + useBooks) para crear experiencias de usuario consistentes y seguras.
