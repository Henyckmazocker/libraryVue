Inicio Rápido

¡Bienvenido a tu biblioteca personal! Esta aplicación te permite organizar y gestionar tu colección de libros y películas de forma intuitiva.

Autenticación

La aplicación utiliza Google OAuth para el login. Cada usuario tiene su biblioteca personal completamente separada.

Primeros pasos:

  1. 1Inicia sesión con tu cuenta de Google
  2. 2Explora las secciones "Libros" y "Películas"
  3. 3Comienza a agregar contenido a tu biblioteca
  4. 4Organiza con estados y tags personalizados

Gestión de Libros

Agregar un Libro:

  1. Ve a la sección "Libros"
  2. Haz clic en "Agregar Libro"
  3. Escanea el código de barras o introduce el ISBN manualmente
  4. La información se cargará automáticamente
  5. Asigna estados, calificación y tags según prefieras

Estados Disponibles:

  • Tengo: Libro que posees físicamente
  • Leído: Libro que ya has terminado de leer
  • Quiero leer: En tu lista de pendientes
  • Leyendo: Libro que estás leyendo actualmente
  • Quiero comprar: En tu lista de deseos
  • Abandonado: Libro que decidiste no terminar

Gestión de Películas

Agregar una Película:

  1. Ve a la sección "Películas"
  2. Haz clic en "Agregar Película"
  3. Busca por título
  4. Selecciona la película correcta de los resultados
  5. Configura estados, calificación y tags

Estados Disponibles:

  • Tengo: Película que posees (DVD, Blu-ray, digital)
  • Visto: Película que ya has visto
  • En lista de reproducción: Películas por ver
  • Quiero comprar: En tu lista de deseos
  • Abandonado: Película que no terminaste

Tags Personalizados

Los tags te permiten crear tu propio sistema de organización más allá de los estados predefinidos.

Ejemplos de Tags Útiles:

Para Libros:
  • Favoritos
  • Ciencia Ficción
  • Biografías
  • Para regalar
  • Recomendados por amigos
  • Libros de trabajo
Para Películas:
  • Favoritas
  • Terror
  • Comedias
  • Noche de películas
  • Clásicos
  • Ver con familia
Consejo

Puedes asignar múltiples tags a cada libro o película. Usa colores para categorizar visualmente (ej: azul para géneros, verde para favoritos).

Actualizar la Aplicación

Importante

Cuando descargues actualizaciones de la aplicación, es necesario reiniciar Docker para que los cambios se apliquen correctamente.

Proceso de Actualización:

  1. 1Descarga las actualizaciones del código (Git pull o descarga)
  2. 2Abre una terminal/línea de comandos
  3. 3Navega al directorio de la aplicación
  4. 4Ejecuta los siguientes comandos:
Windows (PowerShell/CMD):
cd "ruta\a\tu\proyecto\libraryVue"
docker-compose down -v
docker-compose up --build -d
Linux/Mac (Terminal):
cd /ruta/a/tu/proyecto/libraryVue
docker-compose down -v
docker-compose up --build -d

Explicación de los comandos:

  • docker-compose down -v: Detiene y elimina contenedores y volúmenes
  • docker-compose up --build -d: Reconstruye y levanta los contenedores en segundo plano
Tiempo estimado

El proceso completo toma entre 2-5 minutos. La aplicación estará disponible nuevamente en http://localhost:8080

Problemas Comunes

Solución: Asegúrate de haber ejecutado correctamente los comandos de Docker:
docker-compose down -v
docker-compose up --build -d
Si persiste el problema, verifica que Docker esté funcionando: docker --version

Posibles causas:
  • Problemas de conectividad a internet
  • Cookies/cache del navegador
  • Configuración de Google OAuth
Solución: Limpia el cache del navegador e intenta nuevamente.

Requisitos:
  • El navegador debe tener permisos de cámara
  • Buena iluminación para el código de barras
  • Navegador moderno (Chrome, Firefox, Safari)
Alternativa: Siempre puedes introducir el ISBN manualmente.
