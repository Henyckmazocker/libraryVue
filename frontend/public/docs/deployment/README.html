Visión General

Opciones de Deployment

Library Vue puede desplegarse de múltiples formas: usando Docker para máxima portabilidad o deployment tradicional en servidor web. Esta guía cubre ambas opciones.

Docker (Recomendado)
  • Entorno aislado y reproducible
  • Fácil escalado
  • Configuración simplificada
  • Múltiples entornos consistentes
Tradicional
  • Control directo del servidor
  • Optimización específica
  • Integración con infraestructura existente
  • Sin dependencias de contenedores

Deployment con Docker

Ventajas de Docker

Docker proporciona un entorno consistente entre desarrollo y producción, facilita el escalado y simplifica las actualizaciones.

Preparación

# 1. Clonar repositorio
git clone https://github.com/tu-usuario/libraryVue.git
cd libraryVue

# 2. Configurar variables de entorno
cp .env.example .env
nano .env

# 3. Configurar Google OAuth
# Editar GOOGLE_CLIENT_ID en .env

Deployment en Producción

# 1. Construir imágenes de producción
docker-compose -f docker-compose.prod.yml build

# 2. Levantar servicios
docker-compose -f docker-compose.prod.yml up -d

# 3. Verificar servicios
docker-compose -f docker-compose.prod.yml ps

# 4. Ver logs
docker-compose -f docker-compose.prod.yml logs -f

Configuración docker-compose.prod.yml

version: '3.8'
services:
  frontend:
    build:
      context: ./frontend
      dockerfile: ../docker/frontend/Dockerfile.frontend.prod
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./ssl:/etc/ssl/certs
    environment:
      - NODE_ENV=production

  backend:
    build:
      context: ./backend
      dockerfile: ../docker/backend/Dockerfile.backend.prod
    ports:
      - "8080:8080"
    environment:
      - APP_ENV=production
      - DB_HOST=database
    depends_on:
      - database

  database:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: ${DB_ROOT_PASSWORD}
      MYSQL_DATABASE: ${DB_NAME}
    volumes:
      - mysql_data:/var/lib/mysql
      - ./docker/database/init.sql:/docker-entrypoint-initdb.d/init.sql
    ports:
      - "3306:3306"

volumes:
  mysql_data:

Actualización en Producción

# 1. Backup de base de datos
docker-compose exec database mysqldump -u root -p library_vue > backup.sql

# 2. Descargar últimos cambios
git pull origin main

# 3. Reconstruir imágenes
docker-compose -f docker-compose.prod.yml build --no-cache

# 4. Aplicar actualizaciones
docker-compose -f docker-compose.prod.yml up -d

# 5. Verificar funcionamiento
docker-compose -f docker-compose.prod.yml ps

Deployment Tradicional

Requisitos del Servidor

Para deployment tradicional necesitas un servidor web (Apache/Nginx) con PHP 8.1+, MySQL 8.0+, y Node.js 18+ para el build del frontend.

Preparación del Servidor

# Ubuntu/Debian
sudo apt update
sudo apt install nginx php8.1-fpm php8.1-mysql php8.1-mbstring php8.1-xml composer nodejs npm mysql-server

# CentOS/RHEL
sudo yum install nginx php-fpm php-mysql composer nodejs npm mysql-server

Configuración del Backend

  1. 1Subir archivos del backend al servidor
  2. 2Instalar dependencias PHP
  3. 3Configurar base de datos
  4. 4Configurar servidor web
# En el servidor
cd /var/www/library-vue-backend
composer install --no-dev --optimize-autoloader

# Configurar permisos
chmod -R 755 storage/
chmod -R 755 cache/
chown -R www-data:www-data storage/ cache/

# Configurar .env
cp config/.env.example config/.env
nano config/.env

Configuración de Nginx

# /etc/nginx/sites-available/library-vue
server {
    listen 80;
    server_name api.example.com;
    root /var/www/library-vue-backend/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.ht {
        deny all;
    }
}

# Frontend
server {
    listen 80;
    server_name app.example.com;
    root /var/www/library-vue-frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}

Build del Frontend

# En tu máquina de desarrollo
cd frontend
npm install
npm run build

# Subir dist/ al servidor
scp -r dist/ user@server:/var/www/library-vue-frontend/

Seguridad de Configuración
  • Nunca commits archivos .env al repositorio
  • Usa contraseñas seguras para base de datos
  • Configura CORS apropiadamente
  • Valida URLs de Google OAuth

Seguridad

SSL/HTTPS

Obligatorio en producción para Google OAuth y seguridad de datos.

# Certificado Let's Encrypt
sudo certbot --nginx -d app.example.com -d api.example.com
Firewall

Configurar firewall para proteger puertos innecesarios.

# UFW básico
sudo ufw allow 22
sudo ufw allow 80
sudo ufw allow 443
sudo ufw enable
Checklist de Seguridad
✅ Obligatorio
  • SSL/HTTPS configurado
  • Contraseñas seguras
  • Firewall configurado
  • Google OAuth URLs validadas
  • Logs de seguridad activos
🔧 Recomendado

Resolución de Problemas

Problemas Comunes de Deployment
Error 500 en API

Causas posibles:

  • Permisos incorrectos en storage/
  • Configuración de base de datos incorrecta
  • PHP extensions faltantes
  • Errores en .env

Solución:

# Verificar logs
tail -f storage/logs/api-$(date +%Y-%m-%d).log

# Verificar permisos
chmod -R 755 storage/
chown -R www-data:www-data storage/
Frontend no carga

Causas posibles:

  • Build incompleto o corrupto
  • Configuración incorrecta de Nginx
  • URLs de API incorrectas

Solución:

# Rebuild frontend
npm run build

# Verificar configuración Nginx
nginx -t
Google OAuth no funciona

Solución:

  • Verificar Client ID en Google Console
  • Confirmar URLs autorizadas (debe incluir https://)
  • Verificar que SSL esté funcionando
  • Comprobar CORS headers
