Visión General

El frontend de Library Vue está construido con Vue.js 3, utilizando Composition API, Pinia para gestión de estado, y Vue Router para navegación. La arquitectura está diseñada para ser modular, reutilizable y fácil de mantener.

Componentes

UI Components
  • BaseButton: Botón reutilizable con variantes
  • BaseInput: Input con validación
  • BaseModal: Modal genérico
  • LoadingSpinner: Indicador de carga
  • RatingComponent: Sistema de calificación con estrellas
Library Components
  • BookCard: Tarjeta de libro con acciones
  • MovieCard: Tarjeta de película
  • BookForm: Formulario para agregar/editar libros
  • MovieForm: Formulario para películas
  • SearchForm: Búsqueda avanzada
Patrón de Componentes

Todos los componentes siguen el patrón de Composition API con props tipados, eventos bien definidos y slots para máxima reutilización.

Composables

Sistema de Composables

Los composables proporcionan lógica reutilizable para diferentes aspectos de la aplicación:

Autenticación
  • useAuth - Gestión de autenticación principal
  • useGoogleAuth - Integración con Google OAuth
  • usePermissions - Control de permisos
Biblioteca
  • useBooks - Gestión de libros
  • useMovies - Gestión de películas
  • useSearch - Búsqueda avanzada
Ver Documentación Completa de Composables

Routing

Configuración de Rutas
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'
import { useAuth } from '@/composables/useAuth'

const routes = [
  {
    path: '/',
    name: 'Home',
    component: () => import('@/views/Home.vue'),
    meta: { requiresAuth: true }
  },
  {
    path: '/books',
    name: 'Books',
    component: () => import('@/views/Books.vue'),
    meta: { requiresAuth: true }
  },
  {
    path: '/movies',
    name: 'Movies',
    component: () => import('@/views/Movies.vue'),
    meta: { requiresAuth: true }
  }
]
Protección de Rutas

Todas las rutas principales requieren autenticación. El guard de navegación verifica el estado de autenticación antes de permitir el acceso.

Gestión de Estado

Pinia Stores
  • Auth Store: Estado de autenticación global
  • Books Store: Estado de libros
  • Movies Store: Estado de películas
Composables
  • Lógica reactiva encapsulada
  • Reutilización entre componentes
  • Testeo más sencillo
Patrón Híbrido

Utilizamos una combinación de Pinia stores para estado global y composables para lógica específica, aprovechando lo mejor de ambos enfoques.

Desarrollo

Comandos de Desarrollo
# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Build para producción
npm run build

# Previsualizar build
npm run preview

# Linting
npm run lint

# Testing
npm run test
Mejores Prácticas
  • Usar Composition API
  • Componentes pequeños y enfocados
  • Props y eventos bien tipados
  • Nomenclatura consistente
Consideraciones
  • Lazy loading de rutas
  • Optimización de bundle
  • Manejo de errores global
  • Accesibilidad (a11y)
